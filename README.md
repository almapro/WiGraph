# WiGraph - Wireless Network Visualization Tool inspired by BloodHound

WiGraph is a powerful visualization tool designed to help network administrators and security professionals analyze and visualize wireless network topologies. Built on React Flow, it provides an intuitive interface for mapping and understanding wireless network structures and device relationships.

## Key Features

- **Real-time Network Visualization**: Create dynamic visual representations of wireless networks
- **Integration with Network Analysis Tools**: Seamlessly import data from popular wireless analysis tools
- **Interactive Layouts**: Automatic and manual node positioning for optimal visualization

## Integration with Network Analysis Tools

WiGraph is designed to work alongside popular wireless network analysis tools:

### Kismet Integration

- Import `.json` files generated by `kismetdb_dump_devices`
- Visualize network topology with detailed device information

### Airodump-ng Integration

- Import `.netxml` files generated by airodump-ng
- Visualize BSSIDs, ESSIDs, and client associations

## Installation

### Prerequisites

- Node.js 18.0 or higher
- npm 9.0 or higher
- Neo4j Database 5.0 or higher

### Steps

1. Clone the repository:

```bash
git clone https://github.com/almapro/WiGraph
```

2. Install dependencies:

```bash
yarn install
```

3. Start the development server:

```bash
yarn dev
```

## Usage

### Creating a Network Map

1. Start by adding a Wifi node:

   - Drag and drop a Wifi node from the node palette
   - Enter the necessary information (e.g., SSID, BSSID, Password)

2. Add client nodes:

   - Drag and drop a Client node from the node palette
   - Enter the necessary information (e.g., Client Name, MAC Address, IP Address)

3. Add relations:
   - Drag a connection between nodes to create a relation

### Importing Data

#### Using Kismet

1. Generate a `.json` file using `kismetdb_dump_devices`
2. Import the file into WiGraph:
   - Click on the "Import from..." button in the top-right corner
   - Choose "Kismet" from the "Import Source" dropdown
   - Select the file you want to import
   - WiGraph will automatically parse the data and create a visual representation for it

#### Using Airodump-ng

1. Generate a `.netxml` file using airodump-ng (automatically generated if not omitted)
2. Import the file into WiGraph:
   - Click on the "Import from..." button in the top-right corner
   - Choose "Airodump" from the "Import Source" dropdown
   - Select the file you want to import
   - WiGraph will automatically parse the data and create a visual representation for it
